# Project Instructions

This repository is a public experiment and handbook for improving human-AI collaboration and Codex skills.

## Filesystem

- Keep every project file, generated artifact, cache, and temporary file under this repository root.
- Do not place project content in a parent directory, another repository, or a user/system directory.
- Do not modify external skill installations while working on this repository.

## Web Operations

- Do not use built-in Browser Use in the Windows app.
- Use the Chrome plugin when an authenticated or interactive web operation is required.

## Delivery Workflow

For software changes, use this default sequence:

1. State the goal and acceptance boundary.
2. Implement the shortest runnable vertical slice.
3. Run one risk-matched focused verification.
4. Commit the result.

Do not introduce TDD, BDD, ATDD, red-green-refactor, full regression suites, multi-viewport matrices, dual-axis review, repeated quality gates, or redundant validation unless the user explicitly requests them or the change has a documented high-risk boundary.

## Public Privacy

- Do not commit private project names, machine paths, usernames, account details, thread IDs, task IDs, internal system names, secrets, or identifiable business information.
- Use generic, reproducible examples in research, playbooks, skills, and experiments.
