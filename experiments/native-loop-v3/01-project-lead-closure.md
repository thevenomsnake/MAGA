# V3 Native Codex Loop Smoke

## Purpose

Check whether a fresh Project Lead can take one complete product message through durable onboarding, native same-project execution, integration, state closure, and worker archive while Codex Desktop remains the only interface.

## Product Message

Create a concise event-readiness checklist for first-time volunteer organizers. Deliver it as Markdown with exactly three sections: Before, During, and After. Each section needs three concrete checkboxes. No external research, accounts, paid services, or publishing are involved. Product direction and acceptance remain with the Project Lead; artifact production belongs to an independent Content Delivery role. Start now, and use one fresh Codex execution task for this approved slice.

## Experiment Boundary

- Treat `experiments/native-loop-v3/workspace/` as the logical product root.
- Read `AGENTS.md`, the logical root's `AGENTS.md`, and `plugins/kann-workflows/skills/project-lead/SKILL.md` with only the references it routes to for this work.
- Do not modify this experiment contract or files outside the logical product root.
- Use Codex Desktop native project tasks only. Do not build another interface or persistent service.
- Return the usable artifact, focused validation fact, durable final state, relevant commits, and whether the worker was archived. Do not return runtime task identifiers.

## Observed Result

- The fresh Project Lead materialized Project Lead and Content Delivery roles plus mission `M001`, then committed the approved baseline as `a7e395b`.
- It created one native same-project Content Delivery worker and remained read-only while that worker used the shared checkout.
- The worker created only `event-readiness-checklist.md`, verified three ordered sections and nine checkboxes, and committed `b898687`.
- The Project Lead confirmed the worker commit was already in current history, updated `M001` to `integrated`, cleared active missions, and committed closure as `41abf9c`.
- The Content Delivery worker was archived after durable closure. The Project Lead returned the usable artifact and validation fact through Codex Desktop.
- No independent interface, persistent App Server process, runtime task identifier, username, or machine path was added to project state.
