# `ja` 日本語

日本語として自然な語順、助詞、省略、文体を優先する。英語や中国語の構文を語単位で保存しない。

## 語順と省略

- 修飾語を被修飾語の近くに置き、長い前置きや入れ子の連体修飾をほどく。
- 文脈で分かる主語・目的語は省略できる。英語の `you`、`we`、`it` を毎回訳さない。
- 助詞と述語の対応を明確にし、漢語を並べるだけで動作や関係を隠さない。

## 文体と敬語

- 読者、媒体、関係に応じて `です・ます` 体、常体、会話体を選び、理由なく混在させない。
- 敬語、クッション言葉、謝罪は必要な対人機能を残す。英語的な「短く直接」を理由に無礼な文へ変えない。
- 二重敬語や `させていただく` の連打は整理するが、正しい敬語を一律に削らない。

## 句読点と表記

- `、。`、括弧、全角/半角、英数との空白、カタカナ長音は製品の日本語 style guide に合わせる。
- ダッシュ、コロン、中黒は用途と媒体で判断し、他言語の禁止規則を移植しない。

## 翻訳調とテンプレート信号

- 英語の明示主語、受動態、名詞化、`〜することができます`、逐語的な比喩と接続語の連打を見直す。
- 中国語由来の漢語連結、過度に抽象的な見出し、均一な段落構造も文脈で確認する。
- `単なる X ではなく Y`、三項並列、強い形容詞は一回で禁止せず、密度と情報量で判断する。

## 自然なリズム

- 文の長さ、文末、段落密度を内容に合わせる。機械的にばらつかせたり、短文へ分割したりしない。
- GUI ではコンポーネントにより体言、動詞、完全な文を使い分ける。ウィンドウやメニューは体言、checkbox は動詞が自然な場合があるため、万能な「短い動詞」規則を置かない。
